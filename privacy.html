Privacy policy

JARVIS · last updated 29 September 2026

JARVIS is a personal voice assistant with a single user: the person who runs it on their own computer. This page explains what it does with Google data.

What JARVIS accesses

  • Google Calendar events on the user's own calendars: title, start and end time, location, and whether the event is recurring or was organized by someone else. Event descriptions are not read.
  • Free/busy information for those calendars, to find open time slots.

JARVIS creates, moves or deletes events only when the user asks it to.

How the data is used

Calendar data is used only to answer the user's own requests (reading the agenda, finding free time, adding or changing events). To phrase an answer, the details of the events involved in that request are sent to the language model service that powers the assistant. Calendar data is not sold, not shared with anyone else, and not used for advertising.

Where it is stored

The Google sign-in token is stored only on the user's own computer, readable by that user alone. JARVIS does not copy calendar events into its knowledge base; Google Calendar remains the place they are kept. The conversation history, which can mention an event the user asked about, stays on the user's computer.

Removing access

Access can be withdrawn at any time at myaccount.google.com/permissions; deleting the token file on the computer has the same effect.
